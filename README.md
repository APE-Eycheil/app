# APE Eycheil — appli d'organisation

Appli web installable (PWA) pour le bureau et les parents impliqués de l'APE d'Eycheil : événements, tâches, listes de courses, dépenses avec justificatif, présence, créneaux de bénévoles.

- Besoins : [`cahier-des-charges.md`](cahier-des-charges.md)
- Conventions et méthode de travail : [`CLAUDE.md`](CLAUDE.md)
- Stack : HTML / CSS / JS sans compilation, Supabase, GitHub Pages
- État : phase 0 (squelette). Suite : [`AI/Pending/Phase0-MiseEnPlace.md`](AI/Pending/Phase0-MiseEnPlace.md)

Ce dépôt est public : code seulement, jamais de données, de photos ni de secrets.

## Essayer en local
```bash
python -m http.server 8080
```
puis ouvrir http://localhost:8080
